# Etap 1 — Wprowadzenie

## Cel etapu

- Ustawić wspólne rozumienie, czym jest GitHub Copilot
- Pokazać, że to nie tylko autocomplete
- Osadzić Copilota w codziennej pracy z kodem

---

## Czym jest GitHub Copilot?

- Asystent AI dla programistów
- Pomaga pisać, wyjaśniać i poprawiać kod
- Działa na bazie kontekstu, który mu dajesz

---

## Copilot to platforma, nie autocomplete

- Inline suggestions
- Chat w IDE
- Agent mode
- Copilot CLI
- GitHub.com i PR workflow

---

## Gdzie działa Copilot?

- VS Code
- Visual Studio
- JetBrains
- Terminal
- GitHub.com

---

## Tryby pracy, które pokażemy

- **Inline** — szybkie uzupełnianie kodu
- **Chat** — pytania, wyjaśnienia, iteracja
- **Agent** — większe zadania i zmiany w wielu plikach
- **CLI** — praca z repo w terminalu

---

## Modele i koszt

- Auto / szybki model / reasoning
- Koszt zależy od modelu i tokenów
- Dobry kontekst = mniej zbędnych iteracji
- Nie każdy ruch agenta to osobny premium request

---

## PHP i .NET

- Zasady pracy z Copilotem są podobne
- Różni się ekosystem i konwencje
- AI pomaga w każdym przypadku, ale nie zastępuje znajomości frameworka
